Get Brim

  1. Download the .dmg and drag Brim to Applications.
  2. Open it. The first time, go to System Settings › Privacy & Security and click Open Anyway.
  3. Allow Accessibility, for the volume and brightness keys, and Bluetooth, for headphone battery.

Why the extra step? Brim isn't notarized by Apple, which needs a paid developer account. The code is open, so anyone can check what it does.
